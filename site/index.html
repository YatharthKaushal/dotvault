dotvault

Find, read, edit, store and share your .env files from one place.

Early development. See the latest release for the current version. You can also build from source.

Install

Linux

curl -fsSL https://yatharthkaushal.github.io/dotvault/install.sh | sh

x86_64 and aarch64, glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 or later). Installs dotvault into ~/.local/bin. If that folder is not on your PATH, the installer adds it for new terminals by appending one line to your shell's startup file, and tells you which.

macOS

curl -fsSL https://yatharthkaushal.github.io/dotvault/install.sh | sh

Apple Silicon and Intel. Installs dotvault into ~/.local/bin and, if that folder is not on your PATH, adds it for new terminals through your shell's startup file (~/.zshrc for zsh). The binaries are not signed; files fetched by this script are not quarantined by macOS.

Windows (PowerShell)

irm https://yatharthkaushal.github.io/dotvault/install.ps1 | iex

x64. Installs dotvault.exe into %LOCALAPPDATA%\Programs\dotvault and adds that folder to your user PATH, leaving every other entry as it was, and to the current window, so dotvault works at once; terminals that were already open need to be reopened. No administrator rights needed.

The scripts download the archive for your platform from GitHub Releases, check its SHA-256 checksum, and copy the binary into place. They never use sudo. Read them first: install.sh, install.ps1.

Options

VariableEffect
DOTVAULT_VERSIONInstall this release, for example v0.1.0. Default: latest.
DOTVAULT_INSTALL_DIRInstall into this folder.
DOTVAULT_NO_MODIFY_PATHSet to 1 to leave PATH and your shell startup files alone. On Linux and macOS you can pass --no-modify-path instead.

Set them on the sh side of the pipe:

curl -fsSL https://yatharthkaushal.github.io/dotvault/install.sh | DOTVAULT_VERSION=v0.1.0 sh

Windows: $env:DOTVAULT_VERSION = "v0.1.0" before running the installer. Run an installer again to update. To uninstall, delete the binary and the PATH setup; the README lists the steps.

Build from source

Needs Rust 1.85 or newer and a C compiler (Linux: build-essential or gcc; macOS: Xcode Command Line Tools; Windows: Visual Studio C++ Build Tools).

git clone https://github.com/YatharthKaushal/dotvault.git
cd dotvault
cargo install --path crates/dotvault-cli --locked

This puts dotvault in ~/.cargo/bin (%USERPROFILE%\.cargo\bin on Windows).
